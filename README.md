Welcome to AttainableRegionTutorial.jl! A Julia package that provides a tutorial on how to 
generate attainable regions for a single mixed suspension mixed product removal (MSMPR) 
crystallizer. 

It serves as (part of) the accompagning material for Chapter 28 "Population Balance-Enabled 
Modelling for Batch and Continuous Crystallization Processe" of the book "Chemical 
Engineering in the Pharmaceutical Industry, Third Edition: Active 
Pharmaceutical Ingredients" edited by David J. and Mary Tanya am Ende.

Details on use of the package can be found in the [documentation](https://thomvet.github.io/AttainableRegionTutorial.jl/stable/).
